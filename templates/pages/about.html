About TaskFlow

This is a small demo showing how Flask + HTMX can feel like a single-page app without writing any client-side JavaScript framework.

Every tab swaps the #page region in place, updates the URL with hx-push-url, and browser back/forward just work because HTMX keeps a history cache of each swap.

Built with Flask, Jinja, and htmx.
