About TaskFlow

This is a small demo showing how Flask + a bit of vanilla JavaScript can feel like a single-page app without any client-side framework.

Every tab swaps the #page region in place via a small fetch()-based helper, updates the URL with history.pushState, and browser back/forward work because the same helper re-fetches the fragment for the current URL on popstate.

Built with Flask, Jinja, and a small vanilla JS helper (see static/app.js).
